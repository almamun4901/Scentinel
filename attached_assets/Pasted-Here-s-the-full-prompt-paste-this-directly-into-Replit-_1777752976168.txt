**Backend — build these Express endpoints:**

`GET /api/search?q=` — fuzzy search fragrances by name or house using fuse.js. Returns top 10 matches with name, house, year, concentration, accords array, notes (top/heart/base), longevity (1–5), sillage (1–5), price_gbp.

`POST /api/dupes` — body: `{ fragranceName, priceCeiling }`. Loads all fragrances from fragrance-data.json. Computes cosine similarity between accord vectors of the target fragrance and every other fragrance in the dataset. Returns top 5 matches sorted by similarity score descending, each with: name, house, similarity_pct (0–100), price_gbp, price_delta (savings vs original), accords.

`POST /api/context` — body: `{ fragranceName, weatherTemp, weatherDesc, occasion, timeOfDay, ownedFragrances[] }`. Scores each fragrance in ownedFragrances against the context using these weighted rules: longevity fit for occasion (office = medium preferred), sillage fit (office = low/medium), season fit based on temp (>22°C = fresh/citrus bonus, <12°C = woody/spicy bonus), time fit (morning = fresh, evening = oriental/woody). Returns top 3 ranked picks with name, house, match_pct, reason (one sentence).

`POST /api/score` — body: `{ fragranceName, ownedFragrances[], budget }`. Calls the Anthropic Claude API (claude-sonnet-4-6) to generate a blind buy score. Send Claude a structured prompt with the fragrance's accords, notes, longevity, sillage, price, and the user's owned fragrances. Ask Claude to return JSON only with: overall_score (0–100), breakdown (accord_compatibility, community_longevity, batch_consistency, price_value each 0–100), verdict (one of: "Strong buy", "Buy with confidence", "Consider a sample first", "High risk"), flags array (each flag has type: "warn"|"info"|"ok", title, body).

`GET /api/weather?lat=&lon=` — proxy to OpenWeatherMap free API. Returns temp_c, description, humidity. Use env var OPENWEATHER_KEY.
